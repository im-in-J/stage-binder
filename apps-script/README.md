# 서버 설치 (한 번만, 약 5분)

사이트의 **출결 공유·관리자 편집**은 서버 하나가 맡습니다. Google 계정만 있으면 되고 무료입니다.
`server.gs` 한 파일이 전부이며, 데이터는 그 스크립트 안(Script Properties)에만 저장됩니다.

서버가 없으면 사이트는 **보기 전용**으로 동작하고, 출결은 각자 브라우저에만 남습니다.

## 1. 스크립트 만들기

1. <https://script.google.com> 접속 → **새 프로젝트**
2. 편집기에 있는 기본 코드를 전부 지우고, 이 폴더의 `server.gs` 내용을 통째로 붙여넣기
3. 위쪽 "제목 없는 프로젝트"를 눌러 이름 지정 (예: `스테이지 바인더`)

## 2. 웹 앱으로 배포하기

1. 오른쪽 위 **배포 ▸ 새 배포**
2. 왼쪽 톱니바퀴 ▸ **웹 앱**
3. 이렇게 설정
   - 다음 사용자로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
4. **배포** ▸ 액세스 승인 ▸ 본인 계정 선택 ▸ (경고 화면이 나오면) 고급 ▸ 프로젝트로 이동 ▸ 허용
5. 나오는 **웹 앱 URL** 복사 — `https://script.google.com/macros/s/……/exec` 형태

## 3. 사이트에 연결하기

URL을 전달해 주면 `index.html`의 `SERVER` 값에 넣어 배포합니다.
(직접 하려면 `index.html`에서 `var SERVER = ""` 를 찾아 따옴표 안에 URL을 넣고 커밋)

## 4. 관리자 비밀번호 정하기

사이트 오른쪽 위 상태 칩 ▸ 관리자 패널 ▸ **처음 입력한 비밀번호가 관리자 비밀번호가 됩니다.**
그 뒤로는 그 비밀번호로만 로그인되고, 패널의 "비밀번호 변경"으로 바꿀 수 있습니다.

## 알아둘 점

- 서버 URL을 아는 사람은 누구나 **출결**은 남길 수 있습니다 (팀 내부 공유용).
  **사이트 편집**은 관리자 비밀번호가 있어야 합니다.
- `server.gs`를 고친 뒤에는 **배포 ▸ 배포 관리 ▸ 연필 ▸ 버전: 새 버전 ▸ 배포** 를 해야 반영됩니다. URL은 그대로입니다.
- 비밀번호를 잊으면: 편집기에서 `resetPin` 함수를 한 번 실행 → 다음 로그인 때 새로 정해집니다.
- 관리자가 저장한 사이트 데이터는 서버가 우선합니다. 저장소의 `data.json`은 서버에 데이터가 없을 때의 기본값이며,
  관리자 패널의 "저장소 기본값으로 되돌리기"로 서버 데이터를 비워 기본값으로 돌아갈 수 있습니다.
