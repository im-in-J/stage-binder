# 출결 서버 설치 (5분)

일정표 탭의 출결을 **모든 멤버가 함께 보도록** 하려면 저장소가 하나 필요합니다.
구글 계정만 있으면 되고, 비용은 들지 않습니다.

설정하지 않아도 사이트는 그대로 동작합니다. 다만 출결이 **각자 브라우저에만** 남고
서로에게 보이지 않습니다.

## 1. 스크립트 만들기

1. <https://script.google.com> 접속 → **새 프로젝트**
2. 편집기의 기본 코드를 모두 지우고 이 폴더의 `attendance.gs` 내용을 붙여넣기
3. 프로젝트 이름을 아무거나 지정 (예: `스테이지 바인더 출결`)

## 2. 웹 앱으로 배포하기

1. 오른쪽 위 **배포 > 새 배포**
2. 톱니바퀴 → **웹 앱** 선택
3. 설정
   - 설명: 아무거나
   - **다음 사용자로 실행: 나**
   - **액세스 권한이 있는 사용자: 모든 사용자**
4. **배포** → 권한 승인 (본인 계정)
5. 나오는 **웹 앱 URL** 복사 — `https://script.google.com/macros/s/....../exec` 형태

## 3. 사이트에 연결하기

1. 사이트 오른쪽 위 상태 칩(관리자/보기 전용)을 눌러 관리자 패널 열기
2. 관리자로 로그인한 상태에서 **출결 서버 URL** 칸에 위 주소를 붙여넣고 **출결 서버 저장**
3. 일정표 탭의 칩이 "모두와 공유됨"으로 바뀌면 완료

## 알아둘 점

- 주소를 아는 사람은 누구나 출결을 남길 수 있습니다. 단톡방 등 팀 내부에만 공유하세요.
- 코드를 고친 뒤에는 **배포 > 배포 관리 > 편집(연필) > 버전: 새 버전 > 배포**를 해야 반영됩니다.
  이렇게 하면 URL은 그대로 유지됩니다.
- 기록을 전부 지우려면 편집기에서 `resetAll` 함수를 한 번 실행하세요.
- 저장 형태는 `{"회차id": {"멤버id": "y|l|n"}}` 입니다 (y=출석, l=지각, n=결석).
  회차 id·멤버 id는 `data.json` 의 값과 같습니다.
